# GovtJobsIndia

GovtJobsIndia is a static government job finder website.

## Features

- Government job search
- Category filters
- Location filters
- Qualification filters
- Salary filters
- Job deadline
- Job details
- Save jobs
- Share jobs
- Responsive design
- SEO-ready structure
- No backend required

## How To Run

Open index.html in a browser.

## How To Add A New Job

Open:

assets/js/data.js

Copy an existing job object.

Change:

- id
- title
- organization
- category
- qualification
- location
- salary
- vacancies
- dates
- eligibility
- selection process
- documents
- application process
- notification URL
- application URL
- official website URL

Save the file.

The new job will automatically appear on:

- Home page
- All Jobs page
- Search
- Category filters
- Job Details

## Important

Always verify recruitment information from the official recruitment notification before publishing it as a current job.

GovtJobsIndia is an independent informational website and is not a government organization.
